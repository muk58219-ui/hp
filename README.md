# 有限会社まんてん. ホームページ（リニューアル版）

岡山・倉敷の工務店「有限会社まんてん.」のホームページを作り直したものです。
文章と写真は現在のサイト（manten-limited.com）から使い、デザインは neie.jp の「写真を大きく、余白を広く、落ち着いたトーン」を参考にしています。

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップ（メインビジュアル・コンセプト・施工事例・TILOC・見学会・お知らせ） |
| `concept.html` | コンセプト「人生を楽しむ家づくり」 |
| `works.html` | 施工事例一覧（絞り込み・写真拡大） |
| `tiloc.html` | 平屋住宅 TILOC |
| `flow.html` | 賢い家づくり4つのポイント |
| `support.html` | 保証・メンテナンス／ZEH |
| `seminar.html` | 家づくり勉強会 |
| `news.html` | 完成見学会・お知らせ一覧 |
| `company.html` | 経営理念・ロゴストーリー・会社概要・アクセス |
| `contact.html` | お問い合わせ・資料請求フォーム |

ヘッダー、メニュー、フッターは `assets/js/main.js` で全ページに共通で差し込んでいます。

## 更新のしかた

- **施工事例を追加する**：写真を `assets/img/works/w32.jpg` のように置き、`assets/js/main.js` の `WORKS` 配列の先頭に `[32, "タイトル"]` を追加します。
- **お知らせ・見学会を追加する**：`assets/js/main.js` の `NEWS` 配列の先頭に追加します。見学会は `event: true`、`end` に最終日、`img` に写真を指定すると見学会カードにも表示されます。終了日を過ぎると自動で「終了しました」になります。
- **色・フォント**：`assets/css/style.css` の先頭にある `:root` で変更できます。

## 未対応・要確認

- **お問い合わせフォームの送信先**：今は画面上で完了メッセージを出すだけで、実際には送信されません。公開前に Formspree などのフォームサービスか、サーバー側の送信処理につなぐ必要があります（`main.js` の「お問い合わせフォーム」の部分）。
- 見学会カードの写真は、同じ物件の写真がないため施工事例の写真を仮に使っています。
- 施工事例はWORKS 13〜31の19件を掲載しています（1〜12は写真未取得）。

## 確認用

URL の末尾に `?shot` を付けると、ローディング画面とアニメーションなしで表示されます（スクリーンショット確認用）。
